# English for Future

Education Leadership English Hub — ta'lim rahbarlari uchun kundalik professional ingliz tili platformasi: sifat ta'minoti, akkreditatsiya, muzokaralar va global yetakchilik. Daraja: B1–B2 dan C1 gacha.

Platforma bitta `index.html` faylidan iborat (barcha skript, uslub va o'quv materiallari ichida), shuning uchun uni ochish uchun server kerak emas.

## Ishga tushirish

- Faylni yuklab olib, brauzerda `index.html` ni oching, yoki
- GitHub Pages orqali: **Settings → Pages → Branch: main / (root)** ni yoqing, sayt `https://nqaae-monitoring.github.io/English-for-Future/` manzilida ochiladi.
